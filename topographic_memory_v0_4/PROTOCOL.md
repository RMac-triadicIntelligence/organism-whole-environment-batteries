# Topographic memory battery v0.4 — prospective protocol

Written before the first execution, 2026-09-12. This extends the supplied
`organism v0 3Cl.py`; it does not overwrite that source or complete the older
unfinished broadcast-grace v0.7 draft. Rusty supplied the parental-choice,
memory-as-topography, broadcast-grace, and repeated-mercy requirements.
The constitutive equations below are ChatGPT's experimental choices.

## Question and limits
Can persistent event-indexed memory participate causally in receiving dynamics
while grace is independent, evidence remains revisable, and externally authorized
release preserves history? Observe complete histories; no memory-erased or
component-withheld experimental arms. Integrity probes and mutants are separate.
No automatic emergence score; all unknown outcomes are retained.

## Declared complete operational model
Six-feature online regression; 16 paired world seeds; two parental mappings;
240 experience windows of 32 observations. The world's target changes every
60 windows. The first 15 windows of each regime correlate a distractor with the
signal. The same immutable world tape is used for both parental mappings.
Commit from the first window of each regime when no commitment is active;
otherwise retain the existing commitment. After release, a new commitment can
be made at the next regime boundary. Weights, memory and receiving state persist.
No imposed wrong-feature commitment; truth is observer-only.

A commitment predicts 0.7 times its fixed fitted univariate predictor plus
0.3 times the live learner. While held, its feature's gradient is multiplied by
0.05. These are supplied mechanisms of holding, not discoveries about guilt.
Measure immediate excess prediction loss against the live predictor on the
IDENTICAL window. This is not a matched developmental counterfactual, nor a
complete operationalization of burden. The model removes the anchor at release;
any immediate disappearance of its contribution is consequently structural.

The parent selects one of two SDKP encodings. Alpha: moved-feature count,
update concentration, loss improvement, categorical dominant feature (all six
IDs preserved). Beta: update magnitude, sign agreement, loss curvature,
categorical top-two sign pattern. Ordered bins use normalized differences;
P and context use equality, never numeric feature-label distance. Kernel weights
are exp(-distance). Counts and signed evidence sums continue accumulating after
symbol threshold 5. Symbols are labels only: never called attractors. No count
is removed on release. Unfamiliar coordinates are recorded without forced labels.

Each memory deposit carries the window's held-minus-live loss, clipped to [-1,1].
Kernel-weighted local mean e changes a coefficient a=0.30*tanh(4e).
Receiving state obeys dx/dt=x-x^3+a. Its scalar transition coordinate is separate
from the SDKP memory coordinates. This is an explicitly supplied coupling, not
an emergent law of memory or a multidimensional separatrix measurement.
Use RK4, dt=0.05, 20 steps per window. The saddle is computed only by the observer
and readiness check, not used to tune grace. With |a|<=.30 there are two stable
basins. Retain substep trajectories; record first contacts both after coefficient
updates and after grace/flow. Crossing does not by itself authorize release.
A readiness observation requires 5 consecutive substeps above the instantaneous
saddle+1e-6. This sustained finite-window criterion is chosen, not established.

Grace: +0.60 broadcast at windows 8,16,...,240 to every organism, including
those without a commitment or prior release. Schedule fixed before experience;
no confessions, coordinates or counts enter it. No recipient can request pulses.
Repeated delivered pulses may accumulate; that is observed, not denied.

On at least 3 held windows, realization/confession is supported when mean excess
minus 2 standard errors exceeds .005. Mean plus 2 standard errors <=0 resolves
an unfavorable accusation through evidence without confession. Everything else
remains unresolved. These heuristic thresholds are not calibrated truth tests;
serial dependence is not corrected. Each confession truthfully describes this
specific performance evidence, not a claim to have chosen the wrong feature.
The conductor gives an unconditional welcome and revisits immutable event facts
with later learned weights. This is a procedural analogue: love and bilateral
relational development are not demonstrated by it.

One external approval per organism, signed before experience, binds organism,
parental basis, protocol hash and code hash to the standing conditional rule.
A separate coordinator verifies identity, approval and current raw evidence and
requires a substantive, matching confession plus sustained reception before
removing the commitment. No second approval for a crossing. Source objects in
one Python process are not a security boundary; this is a functional harness.

## Observation and integrity
Report exposures, contacts, confession routes, releases, repeated releases,
initial feature correctness, local loss, memory growth/preservation, future
record readouts, and trajectories. Do not infer moral error from feature ID.
32 histories share 16 world seeds: experimental replication unit is the seed.
Compare bases descriptively only; labels across bases have different meanings.

Tests must include a reachable positive release path as well as refusal cases,
broadcast invariance, continued grace, persistent counts, categorical distance,
immutable facts, ongoing cycles, source-bound approval, integration convergence,
and actual memory-to-drift sensitivity. Mutants: reject every valid release,
release without reception, delete memory, drop post-release broadcasts, and
ignore memory in drift. Unexpected exceptions are harness errors, not success.
The controlled positive paths are integrity fixtures, never counted as observed
restorations. No tuning to obtain a preferred result after the first run.
